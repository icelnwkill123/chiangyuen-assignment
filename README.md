## ✨ ฟีเจอร์เด่นของระบบ (Key Features)

### 📋 1. ตารางเช็คงานนักเรียน (Student Checklist Matrix)
- **แสดงตารางสถานะครบทุกคนในห้อง**: ระบุชัดเจนว่าเด็กคนไหน **ส่งแล้ว (✅)**, **ยังไม่ส่ง (❌)**, **ส่งล่าช้า (⏰)** หรือ **ตรวจเสร็จแล้ว (⭐)**
- **สวิตช์เช็คงานด่วน (Quick Toggle Switch)**: อาจารย์สามารถคลิกปุ่มสลับสถานะ "ส่งแล้ว" / "ยังไม่ส่ง" ของนักเรียนแต่ละคนในตารางได้ทันทีโดยไม่ต้องเข้าหน้าอื่น เหมาะสำหรับทั้งตรวจงานออนไลน์และเช็คสมุดการบ้านในห้องเรียน
- **แถบเปอร์เซ็นต์ความคืบหน้า (Real-time Progress Bar)**: แสดงสถิติจำนวนนักเรียนทั้งหมด, ยอดส่งงาน (คิดเป็น %), ยังไม่ส่งกี่คน และคะแนนเฉลี่ย
- **ตัวกรองและค้นหา (Filter & Search)**: กรองตามห้องเรียน (เช่น ม.4/1, ม.4/2), กรองตามสถานะการส่ง, และค้นหาด้วยรหัสนักเรียนหรือชื่อ-นามสกุลแบบ Real-time
- **ส่งออกตาราง Excel (Export CSV)**: ส่งออกตารางสรุปผลการส่งงานและคะแนนของนักเรียนทุกคนเป็นไฟล์ Excel CSV พร้อม UTF-8 BOM รองรับภาษาไทยสมบูรณ์

### 👨‍🏫 2. การจัดการและตรวจให้คะแนน (Teacher Management)
- **ตรวจงาน & ให้คะแนน (Grading Interface)**: ดูไฟล์ที่นักเรียนแนบมา (PDF, รูปภาพ, สไลด์, ZIP) หรือลิงก์ภายนอก (Google Drive, GitHub, Canva, Notion) พร้อมให้คะแนนและเขียนคำติชม
- **ชิปข้อความคำชมสำเร็จรูป (Quick Feedback Chips)**: มีปุ่มลัดสำหรับใส่คำติชมทั่วไป เช่น "ยอดเยี่ยมครบถ้วน", "ขาดส่วนสรุป", "ส่งช้าหักคะแนน" ฯลฯ
- **สร้าง/แก้ไข/ลบหัวข้องาน**: กำหนดชื่อวิชา, ชื่องาน, วันเวลาสิ้นสุดกำหนดส่ง, คะแนนเต็ม, และตั้งค่าเปิดรับงานล่าช้าได้
- **จัดการบัญชีรายชื่อนักเรียน (Student Roster)**: เพิ่มหรือลบรายชื่อนักเรียนในระบบ ระบุรหัส เลขที่ และห้องเรียน

### 👨‍🎓 3. สำหรับนักเรียน (Student Portal)
- **ดูรายการงานที่เปิดรับ**: แสดงเวลานับถอยหลัง (Countdown) สถานะเปิดรับ หรือใกล้หมดเวลา
- **ระบบ Auto-Fill รหัสนักเรียน**: เมื่อพิมพ์รหัสนักเรียน ระบบจะดึงชื่อ-นามสกุลขึ้นมาให้อัตโนมัติจากฐานข้อมูล
- **รองรับการส่งงานหลากหลาย**: อัปโหลดไฟล์ (Drag & Drop) หรือกรอกลิงก์ผลงาน
- **ตรวจสอบสถานะงานของฉัน (Check Status)**: ค้นหาด้วยรหัสนักเรียนเพื่อดูคะแนนที่ได้ ข้อเสนอแนะจากอาจารย์ และประวัติการส่งย้อนหลัง

## 🚀 วิธีการรันใช้งานในเครื่อง (Local Run)

เข้าสู่โฟลเดอร์ของโปรเจกต์:
```bash
cd /Users/ice_anucha/.gemini/antigravity/scratch/assignment-system
```

### คำสั่งเริ่มระบบ:
```bash
ruby server.rb
```
หรือรันผ่าน Shell Script:
```bash
./start.sh
```

เปิดเบราว์เซอร์แล้วไปที่: **`http://localhost:8080`**

---

## ☁️ การ Deploy ให้คนอื่นเข้าใช้งานผ่านอินเทอร์เน็ต (Cloudflare Tunnel)

เปิด Terminal แล้วรันคำสั่ง:
```bash
./deploy_cloudflare.sh
```
ระบบจะสร้างลิงก์ HTTPS สาธารณะให้ใช้งานผ่านอินเทอร์เน็ตได้ทันทีโดยไม่ต้อง Forward Port
